# Supabase read model

Project `embe-read-model` (`tpqqzowhndbkmkckpbgv`) in Singapore is reserved for
curated, rebuildable portal data.

Do not store raw medical records, the Obsidian vault, original photos, RAW files,
videos, or service credentials here. Database changes must be added as migrations
and protected with row-level security before any family data is synchronized.
